# ThreatLens AI

AI-powered malware classification and cybersecurity threat intelligence platform: static analysis
(hashing, YARA, signatures, IOCs), a LightGBM malware detector and family classifier, MITRE ATT&CK
behavioral analysis, alerts and incidents, reports, analytics, and an administrator console.

Files are analysed, never executed.

## Try it

Sign in with the shared demo password you were given and one of these accounts:

| Account | Role |
|---|---|
| `analyst@local` | Security Analyst |
| `soc@local` | SOC Team Member |
| `admin@local` | Administrator |
| `researcher@local` | Researcher |

The dashboards are pre-filled with synthetic samples. Upload your own file from **Submit File** as
the analyst or admin. Data is held in memory and resets whenever the Space restarts.
